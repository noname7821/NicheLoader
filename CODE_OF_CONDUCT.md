# Code of Conduct

Welcome to NicheLoader's Code of Conduct! Basic rules for this repository:

- **Be respectful** in issues, pull requests and discussions.
- **Write useful bug reports**: app version, iOS version, steps to reproduce.
- **No piracy**: no paid apps, decrypted IPAs or shared certificates.
- **No trolling or spam.**

Repeated violations will get you blocked from the repository.
