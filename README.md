# NicheLoader (fresh build)

NicheLoader by mintoo – on-device iOS signer, written from scratch in SwiftUI.

## Status
Early scaffold: Files browser, Library with signing screen, Sources (AltStore feeds),
Settings with certificate import, About. The signing engine slot (`Services/Signer.swift`)
is ready to be connected.

## Build
Open `NicheLoader.xcodeproj` in Xcode 16+, or use the `Build IPA` workflow.
